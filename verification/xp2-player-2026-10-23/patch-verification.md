# XP2 播放器 1.1.0 修复记录

用户流程：在网站第六层选择原游戏本地目录，从顶部完整地图选择剧情片段，读取正确的图片、声音与中文译文，并可保存和恢复浏览位置。

## 已修正

- 原转换器按资源文件名取第一个同名对象，部分 CG 实际指向画廊缩略图。本版按 Unity ResourceManager 的原路径绑定，剧情使用的 932 项资源没有缩略图绑定，未解析资源为 0。
- 默认 CG 原先以图片名创建新对象，导致 A→B→A 时 B 仍覆盖 A。本版按原生图层使用固定对象槽位替换；明确指定的独立图层保留。
- 恢复原生 1280×720 舞台坐标；CG 模式隐藏普通立绘，普通背景指令恢复立绘显示规则；清除指令针对运行中的实际对象生效。
- 地图保留全部 1,083 个剧情片段、202 处分叉、1,224 条连接、55 个章节簇。359 个译文资料片段另行浏览，不与剧情地图混排。地图固定在播放区上方，支持缩放、拖动、章节定位、搜索及点击片段跳转。
- 直接跳转使用有效路线重放原始指令，优先沿当前会话已选路径；未选路线按确定的可达路径恢复。没有合法上游路线的独立注释节点从空白入口浏览，并明确提示。不会复用按表格顺序混合的互斥分支状态。
- 新版浏览进度使用独立存储键，旧版记录留在浏览器中。新版记录只保存可校验的路线和播放位置，画面与音乐从原指令重新推导；拒绝伪造画面、非法选择和不兼容进度。

## 浏览器与构建

2026-10-23 本地原站第六层页面和播放器独立页均载入成功；原游戏目录绑定后，开场场景原图与中文对白正常播放。进入第 26 章并逐句推进后，DOM 中只有一张可见 CG，原图 2560×1440、显示 1280×720、原点 (0,0)、层级 15；没有叠放普通立绘，错误面板及控制台无错误。A→B→A 的完整切换顺序另由真实剧情回归脚本验证。

地图搜索、放大和节点跳转通过浏览器操作；390px 宽度下地图保持展开，实际高度 348px，无页面横向溢出，深浅主题正常。选中分支的连线突出显示，其余连接保留并淡化，完整全图模式展示所有连接。

生产构建 `npm run build` 通过，包括编译、类型检查、页面生成和文件追踪。新地图模块和播放器数据包含在受保护路由的构建追踪中。

覆盖包按此前 2026-10-23 完整交付包逐文件计算差异，只收录新文件和变更文件；不含原游戏本体、未变化的网站媒体、依赖目录、构建缓存或环境变量。打包时执行 ZIP CRC 及覆盖后逐文件 SHA-256 一致性校验。

## 限制

条件分支仍由读者手动选择，不模拟原游戏变量；讨论小游戏仍以资料和继续入口展示。部分动画和窗口效果采用近似处理。地图跳转的默认路线是确定的一条合法浏览路线，不能恢复从未选择过的唯一游戏历史；先前停留时间不参与跳转还原，声音按原文基准时长定位。

本地预览使用占位公共配置，未连接真实会员账号或数据库。原站权限逻辑与配置继续沿用；本轮不推送仓库、不部署线上。首次集成的媒体格式专项报告为历史基线，本轮重点回归以上修复内容。
