V5.4 上传步骤

1. 当前线上 Supabase 数据库的 V5.4 迁移已经执行完成，不需要再运行 SQL。
2. 解压完整升级包，打开 knismolagnia-v5-social-auth 文件夹。
3. 进入 GitHub 仓库 knismolagnia-site。
4. 点击 Add file → Upload files。
5. 把 knismolagnia-v5-social-auth 文件夹“里面的全部内容”拖进仓库根目录覆盖同名文件。
6. 点击 Commit changes。
7. 等待 Vercel 最新 Deployment 变为绿色 Ready。
8. 部署后先测试个人资料锁定和管理员“资料修改审核”。

性能建议：
如果动态页面仍明显卡顿，可进入 Vercel 项目 → Settings → Functions，把 Function Region 选择为 Singapore（sin1），让服务器函数更靠近当前位于新加坡的 Supabase 数据库，然后重新部署。
