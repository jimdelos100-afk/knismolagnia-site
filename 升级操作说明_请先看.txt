KNISMOLAGNIA.CLUB V5.2 升级操作说明

本包已经合并 V5、V5.1 和 V5.2 的全部改动。

【你当前这个线上项目最简单的做法】
数据库的 002、003、004 增量升级已经应用到当前 Supabase 项目，因此现在只需要上传新版源码，不要重复运行 SQL。

1. 解压本 ZIP。
2. 打开 GitHub 仓库：jimdelos100-afk/knismolagnia-site
3. 点 Add file → Upload files。
4. 把“knismolagnia-v5-social-auth”文件夹里面的全部内容拖到仓库根目录，同名文件覆盖。
5. 点 Commit changes。
6. 打开 Vercel → knismolagnia-site → Deployments。
7. 等最新部署变成绿色 Ready。
8. 按“测试清单.txt”测试。

【本次 V5.2 重点】
- 管理后台“交流室管理”打开 /admin/discussion，不会离开后台布局。
- Level 2 的同好列表入口移动到本层已发布内容的最底部。
- Level 5 改为聊天式交流室，不再要求标题。
- 所有有 Level 5 权限的成员都可以发送留言。
- 留言显示头像、用户名、等级、完整到秒的时间戳。
- 点击可见成员头像/用户名可进入成员主页并关注。
- 高于自己等级的成员继续遵守隐私规则：只显示等级，其余资料隐藏。
- 管理后台可以查看并删除交流室留言。

【不要做】
- 不要重新运行 001_initial.sql。
- 当前线上项目也不需要重新运行 002/003/004。
- 不要把 Supabase service-role、数据库密码、Resend SMTP 密钥上传 GitHub。
