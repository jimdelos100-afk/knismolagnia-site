映 · 独立剧情播放器 1.0.0
更新日期：2026-10-23

这是独立的通用剧情播放器，内置原创中性短篇《夜班交接》。只使用自行编写的演出 JSON 和配套普通图片、声音、视频。无需安装浏览器插件。

阅读
点击画面或“继续阅读”，也可按空格／回车。文字显示中点击先补全，再次点击继续。通过剧情地图进入任意独立入口，分支和明确的演出完成结果按声明执行。阅读进度在本机自动保存，可导出／回导。

本轮完成的三项
1. 素材装配：按编号、精确相对路径、大小和 SHA-256 校验内置素材及用户显式选择的本地素材。整批核验成功才绑定；失败保留当前资源；未匹配项不读取内容。所选文件不上传、不改写。
2. 二维演出：固定种子的灯点粒子、图集逐帧动画和有限滤镜，按场景时刻直接计算。暂停、恢复和重进可重现。样例效果在 20 秒后结束，等待对白不会自动重新启动效果。
3. 场景校对：结构和潜在可达性检查、当前画面文字／媒体检查、检查点导出回导、参考图透明叠加／差异混合、检查报告。未检查、待人工确认和失败分别记录。

校对使用
切换右上角“演出校对”。“检查内置素材”核验随网站部署的全部素材；它与当前本地绑定是两种状态。
“选择素材目录”或“选择替换素材目录”只绑定网站素材清单认可的文件。可选择 site/assets，路径需要与清单一致。切换作品／模式会重新装配内置素材；浏览器授权的临时文件不会写入导出文档。
在制作阶段替换或增加图片／媒体后，必须重新生成素材清单，部署新的文件与清单。浏览器不会信任所选目录里自带的清单。
“运行场景检查”暂停演出并检查当前可见画面；继续、换场景或改变画面后，该次当前画面检查失效。静态可达不等于条件路线全都已经实测。
“保存检查点”暂停并立即下载 JSON。会话列表提供恢复、再次导出和人工检查状态；重开页面请导入保存的文件。检查点绑定完整演出声明及素材清单，版本变更后明确拒绝。
“选择对照图”支持不超过 20 MB 的 PNG／JPEG／WebP，可调透明度或使用差异混合。参考图只留在当前页面，不随检查点保存。尺寸不同会提示并按比例完整显示。
包内“接口文档”提供一个检查点、参考图和检查报告示例。先导入检查点示例，再选择参考图示例即可演示对照。示例报告保留人工待核对项，不是全流程验收合格证明。

部署
将部署包解压并把 index.html、styles.css、src/、data/、assets/ 放到静态网页服务器。支持放到现有网站的子目录，保留相对结构。正式作品、译文及媒体可直接内置在 data/ 与 assets/，访问者无需额外载入演出包。
使用 HTTP/HTTPS 打开；直接双击 HTML 不受支持。素材哈希需要 HTTPS 或 localhost。媒体服务器需要正确 MIME，视频建议支持字节范围请求；浏览器首次发声需要用户点击。
源码包可运行 node tools/serve.mjs 进行本机预览，默认 http://127.0.0.1:8791/；用 node --test tests/*.test.mjs 运行测试。

制作自己的作品
入口配置为 site/data/player-config.json；演出为 site/data/story.json；译文为 site/data/translations.json；素材清单为 site/data/asset-manifest.json。
新译文文档类型是 story-translations，schemaVersion=2，条目以编号、原文和作品指纹严格对应；空白不覆盖已有译文。
在源码目录运行 node tools/build-assets.mjs，仅处理演出清单明确列出的素材。修改作品、效果或素材版本后，应同步变更指纹并重新生成清单。
校对模式可临时导入自己创作的同格式演出包。若要核验／绑定它的素材，演出包应内嵌 assetManifest；正式发布仍建议使用配置所指的内置包。
接口细节见 docs/，部署 ZIP 中对应“接口文档”。

明确范围
当前二维效果不包含骨骼动画、任意着色器、3D、任意程序脚本或其他引擎专用指令转换。图集按声明网格切片，作者需保证图集尺寸与声明一致。浏览器资源检查不等同于所有帧和全部音轨的解码验收。
不读取其他作品的专用数据格式；不附带任何旧项目的游戏解析器、版本配置或原作素材。此包没有部署到远程网站。
