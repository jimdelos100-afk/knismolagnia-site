# 雪糕少女汉化组官网 · 三层角色互动完整版

这是完整 Next.js 网站源码，包含六层页面、Supabase 登录及后台、数据库迁移、Builder 首页支持、本地设计预览，以及 Level 1、Level 2 和 Level 3 的角色互动。

## 如何使用
1. 在项目根目录打开终端，首次执行 `npm install`。
2. 在项目根目录保留你自己已有的 `.env.local`，至少包含代码使用的 `NEXT_PUBLIC_SUPABASE_URL`、`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`。压缩包不会包含任何私密配置。
3. 本地设计预览：执行 `npm run dev:design`，在 `http://127.0.0.1:3000/level/1` 、`/level/2` 和 `/level/3` 页面下方查看角色；端口以终端显示为准。
4. 正式部署：将源码提交到已有 GitHub 项目，让 Vercel 按 Next.js 默认输出设置进行构建；Production 环境不要配置 `LOCAL_DESIGN_MODE=true` 或 `BUILDER_DESIGN_MODE=true`。

## 角色互动

- Level 1 使用第一套站姿，Level 2 使用第二套透明坐姿；两者放在各层级原有内容之后。第二套素材不包含公园背景。
- 两套均支持 3 种穿搭（原装、白色裤袜、过膝白丝），初始展示完整角色，可拖动移动、滚轮或双指缩放，并通过“回到初始位置”复位。表情不再由访客直接选择。
- 角色移到画面左侧，设置和互动区位于右侧；手机端会按角色、选项的顺序纵向排列。
- 第一层提供“摸摸头、戳一戳、捏一捏、揉一揉”四种动作。动作按钮会触发对应的短暂表情、位移和回应，结束后恢复原表情；直接点击角色不改变表情。
- 第二层保留同样的右侧选项区域，目前不放置动作按钮，方便后续添加。
- 目光只在虹膜范围内平滑移动，并提高了移动范围与响应速度。所有局部形变已移除；静置和动作反应均采用整张角色随机方向、随机强度的整体抖动，动作反应强于静置状态。
- `public/konisi-game/character.js`、`character.css` 和 `models.js` 由三个入口共用。新运行素材是保留透明度的无损 WebP，分别放在 `assets/standing/`、`assets/seated/` 和 `assets/kneeling/`；原有 PNG 和 Level 1 背景仍保留。
- iframe 保持 `sandbox="allow-scripts"`，不开放同源权限。只有公开美术资源路径启用匿名跨域读取，供沙盒中的 WebGL 使用；没有新增账号或后台接口。
- 页面不可见时停止渲染；遵循减少动态效果设置。WebGL 不可用时降级为静态合成，仍可切换穿搭和使用第一层和第三层动作按钮。

## 第三层新增角色

- 第三套为无手机、脸颊旁比耶的透明跪姿角色，保留金发紫瞳和蓝白金服装，全部无鞋。
- 初始白色裤袜，可切换白色短袜、光脚；放在第三层原有内容下方，左侧角色、右侧选项，手机端上下排列。
- 提供摸摸头、戳一戳、捏一捏、揉一揉、挠脚底五个按钮。挠脚底使用独立闭眼笑表情、专属触摸对白和更强随机整体抖动，结束后恢复微笑；连续点击以最后一次动作优先。
- 不设表情选择，直接点击角色不改变表情；保留目光跟随与眨眼，不做头发或身体局部摆动，不添加故事剧情。

## 检查方法

执行 `npx tsc --noEmit` 和 `npm run build`。本地预览需要上文的公开 Supabase 配置，即使使用设计预览也要先提供这两个变量。

在三个层级分别检查拖动、缩放和复位、三种穿搭、鼠标离开后的视线复位、静置动作以及手机滚动。第一层直接点击角色不应改变表情，四个动作按钮应分别产生反应并自动恢复；第二层应显示透明坐姿角色与预留选项区，不能出现公园树木或座椅。

## 不要上传
`.env.local`、`node_modules/`、`.next/`、真实管理密码、Supabase 服务端密钥等。

## 游戏性质
当前互动由分层美术与网页 WebGL 动画实现，不是已经导出 `.moc3` 的 Cubism 模型。

## V5 三层视角与手机版布局

取消全身/半身切换，统一为回到初始位置。桌面按住场景拖动，滚轮缩放；手机单指拖动、双指缩放。另设加减按钮与键盘支持，缩放范围50%～400%。复位只还原角色位置与大小，保留当前穿搭。拖动不触发表情，原有互动与第三层挠脚底保留。

手机小游戏标题与控制区采用紧凑布局，在常见竖屏尺寸中显示于同一屏内。这里优化的是小游戏模块；层级页其它内容仍按原网页布局滚动。小屏横屏采用左右排列，较矮窗口允许控制区滚动，避免隐藏按钮。
