# KNISMOLAGNIA.CLUB V5.3 核心功能升级版

这是在现有 Next.js + Supabase + Resend 网站基础上的**增量升级**。不会重建现有账号系统，也不会要求老用户重新注册。

## 本版新增 / 修复

- 注册改为：邮箱 + 密码 + 8 位邮箱验证码；验证成功后自动登录。
- 注册验证码支持 60 秒重发倒计时。
- 登录状态持久化加固：首页强制动态读取会话，统一正式域名，减少“回首页像退出登录”的问题。
- 用户可上传头像（JPG/PNG/WEBP/GIF，最大 5MB）。
- 用户可设置 500 字个人简介。
- Level 2 新增子页面 `/level/2/members`：同好列表。
- 成员资料按 Level 保护：同 Level 或更低 Level 可见；更高 Level 只显示 Level，其余资料显示 `******`。
- 新增关注功能。
- “我的关注”只在本人账号页显示。
- “谁关注了我”只在本人账号页显示。
- 新增站内实名认证申请：未提交 / 待审核 / 已通过 / 已驳回。
- 实名提交全部进入管理员后台 `/admin/verification`。
- 暂不接真实第三方实名认证平台；数据库已预留 provider/provider_reference/verified_at 字段。
- 新增用户自助删除账户；最后一名管理员无法自助删除。
- 删除账户前要求输入当前密码与“删除我的账号”二次确认。
- 修复受限账号访问 `/account` 可能出现的重定向循环。
- 防止误操作移除或停用最后一名可用管理员。
- 保留 Builder.io 首页可视化编辑能力；Builder 暂时不可用时自动回退原首页。

## 老账号数据

升级 SQL 为 `supabase/migrations/002_member_social_and_verification.sql`，只新增字段、表、函数、策略和头像 bucket，不会删除现有 `auth.users`、`profiles`、`memberships`、投稿、讨论或层级内容。

老用户升级后默认：

- 简介：空
- 头像：沿用旧 avatar_url（若无则为空）
- 实名状态：未提交
- 关注 / 被关注：空
- 原 Level、管理员身份、账号状态：保持不变

**已有线上数据库不要再次运行 `001_initial.sql`。只运行 002。**

## 重要说明

当前“实名认证”只是站内人工审核。暂不收集身份证号码或证件照片。

`.env.example` 中只有 Supabase Publishable Key 与 Builder Public API Key，均为前端公开配置。不要把 Supabase service-role、数据库密码、Resend SMTP 密钥放入 GitHub。

## V5.1 同好与后台成员管理升级

- 同好列表明确展示个人简介，并提供卡片式 / 列表式切换。
- 管理后台成员页显示头像、简介，并可永久删除其他成员账号。
- 后台删除账号具有管理员校验、当前账号保护、最后管理员保护与审计记录。
- `003_admin_member_directory_tools.sql` 为非破坏性增量迁移。

## V5.2 交流室与成员主页升级

- 管理后台交流室入口改为 `/admin/discussion`，保持后台布局。
- Level 2 的同好列表入口移到本层内容最底部。
- Level 5 改为聊天式留言流，所有有本层权限的成员均可发布。
- 留言显示头像、用户名、Level 和精确到秒的时间戳。
- 点击可见成员头像或昵称进入 `/level/2/members/[id]` 成员主页，并可关注。
- 更高 Level 成员继续按既有 Level 隐私规则隐藏头像、昵称与简介。
- 管理后台可查看并删除交流室留言。
- `004_chat_member_profiles.sql` 为非破坏性增量迁移。


## V5.3 留言评论与 Level 显示升级

- 交流室每条留言下新增评论区。
- 每个账号在同一条留言下最多评论一次；数据库唯一约束强制执行，前端提交前和提交后都会提示。
- 管理员隐藏评论后，该账号仍不能在同一留言下再次评论。
- 评论显示头像、用户名、Level 与精确到秒的时间戳，并继续遵守成员资料可见性规则。
- 从交流室进入访客主页会显示“返回交流室”；从同好列表进入则显示“返回同好列表”。
- 网站可见的层级 / 等级标签统一改为 `Level 1`—`Level 6`，数字不再补 0。
- `005_chat_comments_and_level_labels.sql` 为非破坏性增量迁移。


## V5.4

- 实名认证改为姓名 + 身份证号。
- 昵称注册后锁定；简介/头像首次设置后锁定。
- 后续资料修改统一进入管理员审核。
- 新增 `/admin/profile-changes` 资料修改审核。
- 优化会话查询、头像签名请求和数据库索引，减少动态页面等待。
