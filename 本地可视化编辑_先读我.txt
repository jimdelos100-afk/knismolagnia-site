本地可视化编辑版（专供 VS Code / Piny）

1. 备份电脑上原有网站文件夹。
2. 把本压缩包内的文件覆盖复制到原有项目文件夹，不要删除你电脑原有的 .env.local（本压缩包不包含这个文件）。
3. 在你的 .env.local 原有 Supabase 两项下面，单独添加一行： LOCAL_DESIGN_MODE=true
4. VS Code 终端按 Ctrl+C 停止原服务，再运行 npm run dev。
5. 浏览器访问 http://localhost:3000/level/2 至 /level/6，应该看到带「本地设计预览」提示的示例页面。
6. 打开 src/app/level/[level]/page.tsx / LocalLevelPreview.tsx 和共用组件，在 Piny 中修改布局和样式。

安全边界：
* 只在 NODE_ENV=development 且通过本机 localhost / 127.0.0.1 访问、手动启用 LOCAL_DESIGN_MODE=true 时展示示例页面。
* 不会伪造管理员身份，也不会读取真实高级内容、用户数据或下载文件。
* 不会提供 /admin、账号、用户详情等页面的绕过登录入口。
* 正式网站的用户等级验证及数据权限不变；正式发布前仍需自己验证原有访问控制。
* 本地预览只是设计样本。要修改数据库里已发表的真实内容，仍然在正式管理后台操作。

注意：如果你还没把这版代码提交 GitHub，直接在 Vercel 点击 Redeploy 不会应用本地改动。
