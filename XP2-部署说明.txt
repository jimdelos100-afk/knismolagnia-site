第六层 XP2 本地剧情播放器 1.5.0 原生演出与界面版 · 2026-10-24

本次 1.5.0 累计覆盖包可在最初完整包或已安装 1.1.0、1.2.0、1.3.0、1.4.0 的网站上直接合并升级：仅合并 knismolagnia-site 内的变更文件到原仓库，替换同名文件后重新构建部署。不得用覆盖包替换整个网站文件夹。原环境变量与数据库沿用，1.1.0 / 1.2.0 / 1.3.0 / 1.4.0 浏览进度继续兼容。

一、覆盖升级与部署
先备份原仓库，再将覆盖包 knismolagnia-site 文件夹内的文件合并到原仓库根目录，替换同名文件。原网站已有文件继续保留，尤其是 private/story-player、src、public、supabase 和 scripts。整站首次部署仍使用此前的完整部署包，再合并本覆盖包。
沿用原托管平台的 Supabase URL、publishable key 和已有 Builder 配置。不要使用 .env.example 中的占位值。无需新增数据库表，也无需重跑历史 SQL。
Node.js 20 或更新版本；安装 npm ci，构建 npm run build；普通 Node 主机运行 npm start。Vercel 沿用原 Next.js 项目的部署设置。这是有账号权限的网站源码包，不是纯静态网页包。

二、使用
部署后，/level/6 剧情播放器限时公开，至 2026 年 12 月 31 日 00:00（北京时间）自动恢复 requireLevel(6) 检查，以服务器时间为准。原会员资源列表始终保留原有权限。
进入第六层游戏主页，点击“载入游戏目录”或“选择游戏文件夹”，选择原版“性癖討論v1.0.0”或其“性癖討論2_Data”目录。
浏览器核对版本后，按需读取原游戏的图片、声音和视频。不会上传游戏文件，也不会执行 Windows 游戏程序。网站部署包不包含约 3 GB 的原游戏本体。
点击画面或“继续阅读”逐句阅读；静态章节地图放在顶部，按章节选择、按分支层级浏览，只载入一个章节的地图。可展开片段并跳转到对应剧情，无须缩放。点击“上一句”沿已读路径回看。“译文资料”独立切换浏览。全屏内也可逐句前后翻阅、查看本段进度、回览前文、切换自动播放及隐藏或恢复对话框。支持进度自动保存、导出和导入。重新打开页面需要重新选择本地游戏目录。
目录选择建议在新版桌面 Chrome 或 Edge 使用。手机保留响应式界面与可读对白，但手机浏览器的文件夹选择能力不同。

三、已完成的实际范围
解析 56 份原始场景表，提供 55 个有内容的剧情目录（另 1 份为空表）、5,614 行对白、35 个选项标签；另外 3,503 项界面、角色名、标题和讨论字段保存在译文资料中。
全部 10,173 项原文和译文按原编号与原文匹配保留。其中 1,021 项属于原生指令的附注或参数，保留在翻译目录中，不当成对白播放。
舞台引用 932 项本地媒体；读取索引覆盖 2,338 张纹理、348 项音频和 17 个视频。脚本与译文未放入 public，而由服务端路由读取；播放器入口及资源读取仅在上述期限内公开，到期恢复第六层权限检查。会员资源列表不因播放器公开而放开。
播放器配色与网站粉蓝风格及暗色模式联动，保留现有网站的账号、后台、其他层内容和 Live2D。

四、与原游戏的区别
本版用于场景资源与译文浏览。条件分支由读者手动选择，不计算原游戏变量；原生讨论小游戏没有移植，以明确的继续入口和译文资料供浏览。1.5.0 已按原指令补接移动与图像淡化，并把震动限制到原作对话窗口。原 Unity 每帧随机震动采用保留对象、幅度、衰减及时间的可重现浏览器轨迹，随机样本不能宣称逐帧完全一致。原生存档与解锁按本轮要求不继续移植。
因此本版不能替代原 Windows 游戏的完整玩法。具体计数与限制见 private/story-player/data/adapter-report.json。

五、1.5.0 原生演出与原界面细节
原生演出配置独立于 story.json，以原场景行与实际执行时钟定位；包含 1,137 条 Tween、1,188 条对话窗口震动、6,033 条图像进入及 454 条离场相关指令。修正绝对/相对位移、缓动、纹理自身偏移、已有角色说话时不重画默认表情及位置等差异。
换图使用原作交叉淡入：旧图保持完整，新图覆盖上来；淡出仅衰减离场图层。图片未解码时保留已完成的整幅画面，拖动和跳转不按浏览器墙钟临时重播动画。
首页使用本体原作标题、按钮原图并附中文标签；回想与图库使用原作窗口和页签。349 张 CG 使用精确原作缩略图，其余 5 张本作缺失的缩略图按需从对应原图生成。分页、最多两项并发和视口懒加载防止图库一次解码全部图片。
读取原作点击与悬停音效，本体未设置标题 BGM，因此不另添加音乐。设置增加文字速度（默认 20 字/秒）、BGM/SE 分音量及恢复阅读默认项；语音与环境音是原界面保留项，本作未使用，明确禁用。
补齐说话人立绘 1.0 / 非说话人 0.5 亮度的 0.2 秒渐变，不改变原图层顺序、不影响 CG。
旧浏览记录仍可按旧指令时钟恢复，避免破坏原轨迹；从地图、回想或重新开始明确进入片段后使用原生 Default / Add / NoWait 等待时序。新记录附带独立演出语义版本以验证还原。
原 MessageBox_10th 白框仅以低不透明度叠加，姓名与对白一起按原指令震动；上一句、下一句、进度、自动播放等操作条保持稳定。
原作完整玩法仍须另行移植讨论小游戏、计分与变量条件。本版不把这些浏览入口冒充可运行玩法。验证见 verification/xp2-player-2026-10-23/browser-1.5-verification.md。

此前 1.4.0 菜单、速览与本地化
章节地图可折叠，收起状态保存在当前浏览器。地图上方提供原游戏购买链接，文案为“购买游戏本体后直接载入文件夹即可享受汉化版”。
自动翻句速度可在 0.25–4× 之间调整，仅改变对白完整显示后的等待时间；动画和声音维持原速，不改变音调。遇到需要选择的分支、演出结果或本段结束仍会停止。
拖动本段进度条可逐句预览对白及对应 CG，松开后定位并保持暂停。范围仅限当前片段，不自动跨越分支。拖动和定位沿当前阅读路径还原画面与声音。
新增游戏主页、继续阅读、回想档案、CG 库和设置页。回想档案使用原作 SceneGallery 的 15 个条目；CG 库使用原作 Texture 设置中的 354 张事件原画，按原作分类及编号浏览。
其中 341 张有经过实际对白状态核验的入口；另 13 张没有可停留的对白，按钮明确显示“进入所在片段”，并提示无法停在对应对白。所有 354 张均可在图库单独查看精确原图，不用同名缩略图替代。
图库每页最多 12 个选择条目；连接本机游戏目录后，点击查看才读取一张原图。切换预览或离开图库会释放预览占用，不一次解码整个图库。
纹理解码移入后台 Worker。切图先完成资源读取及图片解码，再整体替换舞台；准备时保留上一完整画面。快速拖动产生的过期请求不会覆盖最新位置，避免半帧缺图或新旧 CG 混叠。
设置提供自动翻句速度、总音量与对话底色不透明度。可导入译文、导入图片替换包、导出图片模板或恢复内置汉化。浏览器导入的译文、图片与阅读偏好持久保存在当前浏览器本机，不会上传游戏或改写游戏文件。
向全站发布统一的译文与图片更新，请使用 scripts/xp2-adapter/install-localization.mjs 维护工具，然后按原流程构建部署。模板格式、预览、备份和安装步骤见根目录“本地化维护说明.txt”。日常阅读无需运行该工具。
以上功能重组原作菜单、回想和图库数据，原生讨论小游戏与变量条件仍未复刻；继续按下节及“与原游戏的区别”说明浏览。

六、此前 1.3.0 全屏阅读功能
降低对话区域底色的不透明度，让 CG 更清楚，保留文字阴影保证可读。对话、控制条、历史文本和分支选项均位于全屏画面内，按钮不会随游戏镜头或舞台缩放变小。
显示本段已读对白数、总句数和剩余句数，进度按对白句数计算，不等同于动画时长。全屏内可直接点击“上一句”“下一句”，回退同步恢复对应画面与声音。
点击“文本全览”可查看当前句及此前最多 30 句实际已读对白。点击其中前文可返回对应位置，并保持暂停。未走过的分支不会混入前文；打开全览时暂停自动播放，关闭后可手动继续或重新开启自动播放。
“自动播放”在文字完整显示后按文字长度停留，再继续下一句。遇到需要选择的分支、演出结果或本段结束时停止，可随时点击开启或关闭。页面转到后台时暂停。
“隐藏对话框”收起舞台内的对话、进度和控制条，只保留右下角恢复小按钮；点击该按钮恢复。已开启的自动播放可在隐藏期间继续，遇到分支时仍会停止。
上述操作在普通阅读和全屏内均可使用。窄屏普通模式保留画面下方的大字对白和操作按钮；全屏时使用画面内的响应式对白与控制条。保留原有深浅主题和第六层访问流程。

七、此前 1.2.0 地图与阅读优化
地图改为离线生成的章节摘要和分层分支，浏览时只按需载入当前章节；不创建全游戏节点与后台全场景校对列表。任意剧情仍可通过章节与片段入口跳转。
新增“上一句”，沿真实执行路线还原先前对白、图片与音乐，回退后保持暂停；1.1.0 浏览记录继续兼容。
详细验收见 verification/xp2-player-2026-10-23/chapter-map-verification.md。

八、此前 1.1.0 修复
CG 改为匹配原生资源路径，避免同名画廊缩略图；舞台使用原生 1280×720。默认 CG 在同一图层槽位替换，保留原生明确指定的多图层；CG 演出期间隐藏普通角色立绘。
地图展示全部 1,083 个剧情片段与连接分支；另有 359 个译文资料片段。直接跳转优先沿已走过的路径还原，否则按默认可达路径重建；画面和声音只由该路径推导。旧版自动进度仍留在浏览器，本版使用新的进度空间，避免读取受旧图层错误影响的存档。
详细验收与剩余限制见 verification/xp2-player-2026-10-23/patch-verification.md。

九、验收与维护
此前版本已完成生产构建、类型检查、本地原版目录绑定、实际图片显示、译文对白检查、分支和进度恢复测试，以及手机和深浅主题检查；历史记录按对应版本保留。1.3.0 全屏阅读交互的验证与脚本同样归档在 verification/xp2-player-2026-10-23。1.4.0 原作目录的真实状态检查见 verify-native-catalog.mjs：15 个回想、354 张原画、341 个精确对白入口和 13 个片段入口。

需要重新生成适配数据时，可使用 scripts/prepare-xp2.py；其离线 Python 依赖记录在 scripts/xp2-adapter/requirements.txt。日常部署和玩家使用无需 Python。
