第六层 XP2 本地剧情播放器 1.3.0 全屏阅读版 · 2026-10-23

本次 1.3.0 覆盖包可在已安装 1.1.0 或 1.2.0 的网站上直接合并升级：仅合并 knismolagnia-site 内的变更文件到原仓库，替换同名文件后重新构建部署。不得用覆盖包替换整个网站文件夹。原环境变量与数据库沿用，1.1.0 / 1.2.0 浏览进度继续兼容。

一、覆盖升级与部署
先备份原仓库，再将覆盖包 knismolagnia-site 文件夹内的文件合并到原仓库根目录，替换同名文件。原网站已有文件继续保留，尤其是 private/story-player、src、public、supabase 和 scripts。整站首次部署仍使用此前的完整部署包，再合并本覆盖包。
沿用原托管平台的 Supabase URL、publishable key 和已有 Builder 配置。不要使用 .env.example 中的占位值。无需新增数据库表，也无需重跑历史 SQL。
Node.js 20 或更新版本；安装 npm ci，构建 npm run build；普通 Node 主机运行 npm start。Vercel 沿用原 Next.js 项目的部署设置。这是有账号权限的网站源码包，不是纯静态网页包。

二、使用
用具有 Level 6 权限的原账号进入第六层。点击“选择游戏文件夹”，选择原版“性癖討論v1.0.0”或其“性癖討論2_Data”目录。
浏览器核对版本后，按需读取原游戏的图片、声音和视频。不会上传游戏文件，也不会执行 Windows 游戏程序。网站部署包不包含约 3 GB 的原游戏本体。
点击画面或“继续阅读”逐句阅读；静态章节地图放在顶部，按章节选择、按分支层级浏览，只载入一个章节的地图。可展开片段并跳转到对应剧情，无须缩放。点击“上一句”沿已读路径回看。“译文资料”独立切换浏览。全屏内也可逐句前后翻阅、查看本段进度、回览前文、切换自动播放及隐藏或恢复对话框。支持进度自动保存、导出和导入。重新打开页面需要重新选择本地游戏目录。
目录选择建议在新版桌面 Chrome 或 Edge 使用。手机保留响应式界面与可读对白，但手机浏览器的文件夹选择能力不同。

三、已完成的实际范围
解析 56 份原始场景表，提供 55 个有内容的剧情目录（另 1 份为空表）、5,614 行对白、35 个选项标签；另外 3,503 项界面、角色名、标题和讨论字段保存在译文资料中。
全部 10,173 项原文和译文按原编号与原文匹配保留。其中 1,021 项属于原生指令的附注或参数，保留在翻译目录中，不当成对白播放。
舞台引用 932 项本地媒体；读取索引覆盖 2,338 张纹理、348 项音频和 17 个视频。入口、脚本和译文均经过原有 Level 6 权限检查，未放入公开 public 目录。
播放器配色与网站粉蓝风格及暗色模式联动，保留现有网站的账号、后台、其他层内容和 Live2D。

四、与原游戏的区别
本版用于场景资源与译文浏览。条件分支由读者手动选择，不计算原游戏变量；原生讨论小游戏没有移植，以明确的继续入口和译文资料供浏览。部分震动、动画及窗口效果采用二维近似，部分原生 Tween 预设未移植。
因此本版不能替代原 Windows 游戏的完整玩法。具体计数与限制见 private/story-player/data/adapter-report.json。

五、1.3.0 全屏阅读功能
降低对话区域底色的不透明度，让 CG 更清楚，保留文字阴影保证可读。对话、控制条、历史文本和分支选项均位于全屏画面内，按钮不会随游戏镜头或舞台缩放变小。
显示本段已读对白数、总句数和剩余句数，进度按对白句数计算，不等同于动画时长。全屏内可直接点击“上一句”“下一句”，回退同步恢复对应画面与声音。
点击“文本全览”可查看当前句及此前最多 30 句实际已读对白。点击其中前文可返回对应位置，并保持暂停。未走过的分支不会混入前文；打开全览时暂停自动播放，关闭后可手动继续或重新开启自动播放。
“自动播放”在文字完整显示后按文字长度停留，再继续下一句。遇到需要选择的分支、演出结果或本段结束时停止，可随时点击开启或关闭。页面转到后台时暂停。
“隐藏对话框”收起舞台内的对话、进度和控制条，只保留右下角恢复小按钮；点击该按钮恢复。已开启的自动播放可在隐藏期间继续，遇到分支时仍会停止。
上述操作在普通阅读和全屏内均可使用。窄屏普通模式保留画面下方的大字对白和操作按钮；全屏时使用画面内的响应式对白与控制条。保留原有深浅主题和第六层访问流程。

六、此前 1.2.0 地图与阅读优化
地图改为离线生成的章节摘要和分层分支，浏览时只按需载入当前章节；不创建全游戏节点与后台全场景校对列表。任意剧情仍可通过章节与片段入口跳转。
新增“上一句”，沿真实执行路线还原先前对白、图片与音乐，回退后保持暂停；1.1.0 浏览记录继续兼容。
详细验收见 verification/xp2-player-2026-10-23/chapter-map-verification.md。

七、此前 1.1.0 修复
CG 改为匹配原生资源路径，避免同名画廊缩略图；舞台使用原生 1280×720。默认 CG 在同一图层槽位替换，保留原生明确指定的多图层；CG 演出期间隐藏普通角色立绘。
地图展示全部 1,083 个剧情片段与连接分支；另有 359 个译文资料片段。直接跳转优先沿已走过的路径还原，否则按默认可达路径重建；画面和声音只由该路径推导。旧版自动进度仍留在浏览器，本版使用新的进度空间，避免读取受旧图层错误影响的存档。
详细验收与剩余限制见 verification/xp2-player-2026-10-23/patch-verification.md。

八、验收与维护
此前版本已完成生产构建、类型检查、本地原版目录绑定、实际图片显示、译文对白检查、分支和进度恢复测试，以及手机和深浅主题检查；历史记录按对应版本保留。1.3.0 新增全屏阅读交互的验证与脚本同样归档在 verification/xp2-player-2026-10-23。

需要重新生成适配数据时，可使用 scripts/prepare-xp2.py；其离线 Python 依赖记录在 scripts/xp2-adapter/requirements.txt。日常部署和玩家使用无需 Python。
