本版修复：增加一条独立的本地设计启动命令，避免普通 npm run dev 进程没有读到预览变量。

1. 保留你自己电脑上原有的 .env.local（新版 ZIP 不含真实密钥）。
2. 如果 .env.local 仍有 LOCAL_DESIGN_MODE=true，也无需删除；新命令会直接在启动时传入变量。
3. 在项目根目录的 VS Code 终端，先用 Ctrl+C 停止原来的 npm run dev。
4. 改为运行： npm run dev:design
5. 终端显示 Ready 后，使用 http://127.0.0.1:3000/level/2 （端口以终端显示为准）。
6. 不要将本地设计预览当成真实管理员账号；真实成员、下载及数据库仍需在正式站登录访问。

重要：本地可视化预览是示例内容，不是从数据库同步的真实页面数据。修改共享的组件和样式可同步到正式页面；修改 LocalLevelPreview.tsx 里的示例文本不会改变正式网站上的内容。
运行 npm run dev:design 会只监听本机 127.0.0.1，不能作为正式网站部署命令。
